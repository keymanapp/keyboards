Uzbek Latin 2026
================

Description
-----------
A keyboard for the Uzbek Latin alphabet as amended in 2026 (Law of the Republic of
Uzbekistan No. ORQ-1184 of 21 October 2026, <https://lex.uz/uz/docs/8548754>): the letters
Ö ö, Ğ ğ, Ş ş, Ç ç and the tutuq ʼ (U+02BC MODIFIER LETTER APOSTROPHE). The law takes effect on
22 April 2027.

**The desktop layout follows the layout *proposed* at the Senate on 10 September 2026
("preferred variant" shown by the Department for the Development of the State Language).
It is not an official standard.** No official technical standard for the keyboard layout
had been published when this keyboard was made; the keyboard will be updated if one is.

All keys are US QWERTY except five. The US characters that those five keys displace are
kept on Right Alt (AltGr) on the same key, so nothing is lost.

Desktop layout
--------------

| Key  | Key alone | Shift | Right Alt (AltGr) | Right Alt + Shift |
|------|-----------|-------|-------------------|-------------------|
| `[`  | ö         | Ö     | `[`               | `{`               |
| `]`  | ğ         | Ğ     | `]`               | `}`               |
| `;`  | ş         | Ş     | `;`               | `:`               |
| `'`  | ç         | Ç     | `'`               | `"`               |
| `\`  | ʼ (U+02BC)| ʼ (U+02BC) | `\`          | `\|`              |

* Caps Lock gives Ö Ğ Ş Ç (and Caps Lock + Shift gives ö ğ ş ç), as for A–Z.
* The tutuq is the same with Shift, so it can be typed inside an all-caps word.
* Every other key, with and without Shift, is US QWERTY. Right Alt does nothing on other keys.

Touch layout
------------

* **Phone:** an extra top row `ö ğ ş ç ʼ` (Shift: `Ö Ğ Ş Ç ʼ`), then QWERTY.
* **Tablet:** mirrors the desktop: number row; `ö ğ ʼ` after `p`; `ş ç` after `l`.
* Phone and tablet: longpress `o`→ö, `g`→ğ, `s`→ş, `c`→ç (uppercase on the Shift and Caps layers).
* Longpress `.` → `, ? ! : ; - « » " '`.
* `123` layer: digits, `! @ # $ % ^ & * ( )`, `[ ] { } \ | ; : ' "`, `- _ = + / ? , « »`.
* Shift is one-shot; double-tap Shift (phone) or the Caps key (tablet) for the Caps layer.
