# Kannada Sanskrit Phonetic (OPTITRANS) 
## Description

Kannada Sanskrit Phonetic (OPTITRANS) keyboard is Kannada Sanskrit input method by a modified version of OPTITRANS and Harvard-Kyoto transliteration systems.

You can use all the standard ITRANS key sequences plus key
sequences such as the below.

nk->ಙ್ಕ್, nkh->ಙ್ಖ್, ng->ಙ್ಗ್, ngh->ಙ್ಘ್
nch->ಞ್ಚ್, nCh->ಞ್ಛ್, nc->ಞ್ಚ್, nC->ಞ್ಛ್, nchh->ಞ್ಛ್,
nj->ಞ್ಜ್, njh->ಞ್ಝ್, nT->ಣ್ಟ್, nTh->ಣ್ಠ್, nD->ಣ್ಡ್, nDh->ಣ್ಢ್
c->ಚ್, C->ಛ್, z->ಜ಼್, S->ಷ್, jn->ಜ್ಞ್, R->ಋ

Examples: Type `saMskRta` for ಸಂಸ್ಕೃತ.
