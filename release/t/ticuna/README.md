Ticuna keyboard

Description
-----------
Keyboard for Ticuna (Tikuna, Magüta; ISO 639-3 `tca`) as written in Brazil. On touch devices it is a standard QWERTY
layout with one extra fixed row above it for the Ticuna letters: ã ẽ ĩ õ ũ ü ü̃ ü̃́ and the glottal stop,
written with the apostrophe ( ' ). Shift gives one capital letter, double-tap Shift locks capitals
(Ã Ẽ Ĩ Õ Ũ Ü Ü̃ Ü̃́). Long-press on vowels and c gives the Portuguese accented letters.
The 😀 key opens a built-in emoji tab.

Desktop (and hardware keyboards on phones and tablets): Brazilian ABNT2 layout, the standard keyboard in
Brazil, with dead keys extended for Ticuna: ~ then a vowel: ã ẽ ĩ õ ũ; ¨ (Shift+6) then u: ü; ~ and ¨ (any order) then u: ü̃; ~, ¨ and ´ then u: ü̃́. The glottal stop ( ' ) is the key
left of 1.

Teclado para a língua ticuna (tikuna, magüta) na grafia usada no Brasil: QWERTY com uma fileira fixa
de letras ticuna (ã ẽ ĩ õ ũ ü ü̃ ü̃́ e a glotal ' ) acima das letras. Shift = uma maiúscula; dois toques no Shift
travam as maiúsculas. Segurar as vogais e o c dá os acentos do português.

No computador (e com teclado físico no celular): layout ABNT2 com teclas de acento que fazem as letras ticuna:
~ e depois a vogal: ã ẽ ĩ õ ũ; ¨ (Shift+6) e depois u: ü; ~ e ¨ (qualquer ordem) e depois u: ü̃; ~, ¨ e ´ e depois u: ü̃́. A glotal ( ' ) é a tecla ao lado do 1.
