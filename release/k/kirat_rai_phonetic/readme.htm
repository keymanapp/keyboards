Kirat Rai (Phonetic) Keyboard Unicode 16.0

Official open-source Keyman keyboard for the Kirat Rai script, standardized in Unicode 16.0 (code block U+16D40 to U+16D7F). Designed for Bantawa, Chamling, and Kiranti language communities worldwide.

Features

  • Full Unicode 16.0 coverage: 31 consonants, 9 independent vowels, 8 vowel signs, 10 digits, and punctuation signs.
  • Embedded Kanchenjunga font from Google Fonts / SIL International so characters render correctly on Android and iOS.
  • Intuitive Romanized phonetic layout (e.g. type k → 𖵄, kh → 𖵅, sewaro → 𖵠𖵧𖵟𖵣𖵝𖵩).

Languages Supported

  • Bantawa (bap-Krai)
  • Chamling (rab-Krai)
  • Athpariya (ath-Krai)
