Teclado Kaingang

Teclado QWERTY com uma fileira fixa de letras kaingang acima das letras:

ã ẽ ĩ ũ ỹ á é ó '

A última tecla da fileira é a glotal ( ' ).

Maiúsculas

Toque uma vez no Shift ⇧ para uma letra maiúscula. Toque duas vezes para travar (caps lock); toque de novo para destravar. No começo da frase o teclado já sobe para maiúscula sozinho.

Ã Ẽ Ĩ Ũ Ỹ Á É Ó

Acentos do português

Segure a vogal para ver â à, ê, í, ô õ, ú ü. Segure o c para ç.

Outros atalhos

Dois espaços depois de uma palavra viram ponto final. A tecla 🌐 troca de teclado.

A tecla 😀 abre os emojis (três páginas: rostos, mãos e corações, natureza e coisas). ABC volta para as letras.

No computador (ou com teclado físico)

O teclado segue o ABNT2, o padrão dos computadores no Brasil, e as teclas de acento também fazem as letras kaingang:

  • ~ e depois a vogal: ã ẽ ĩ ũ ỹ
  • ´ e depois a vogal: á é ó
  • A glotal ( ' ) é a tecla ao lado do 1.
  • Com Shift ou caps lock saem as maiúsculas: ~ e Shift+Y = Ỹ.
