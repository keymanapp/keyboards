Description
-----------
Keyboard for Kaingang (ISO 639-3 `kgp`), spoken in southern Brazil (RS, SC, PR, SP). On touch devices it is a standard
QWERTY layout with one extra fixed row above it for the nine Kaingang letters that are not on QWERTY:
the nasal vowels ã ẽ ĩ ũ ỹ, the vowels á é ó, and the glottal stop written with the apostrophe ( ' ), as in pã'i.
Shift gives one capital letter, double-tap Shift locks capitals (Ã Ẽ Ĩ Ũ Ỹ Á É Ó). Long-press gives the
Portuguese accented letters, and the 😀 key opens a built-in emoji tab.

Desktop (and hardware keyboards on phones and tablets): Brazilian ABNT2 layout, the standard keyboard in
Brazil, with dead keys extended for Kaingang: ~ then a vowel: ã ẽ ĩ ũ ỹ; ´ then a vowel: á é ó. The glottal stop ( ' ) is the key
left of 1.

Teclado para a língua kaingang. No celular: QWERTY com uma fileira fixa com as nove letras do alfabeto kaingang que
não estão no QWERTY (ã ẽ ĩ ũ ỹ á é ó e a glotal ' ). Shift = uma maiúscula; dois toques no Shift travam as
maiúsculas. A tecla 😀 abre os emojis.

No computador (e com teclado físico no celular): layout ABNT2 com teclas de acento que fazem as letras kaingang:
~ e depois a vogal: ã ẽ ĩ ũ ỹ; ´ e depois a vogal: á é ó. A glotal ( ' ) é a tecla ao lado do 1.
