Description
-----------
Touch keyboard for Kaingang (ISO 639-3 `kgp`), spoken in southern Brazil (RS, SC, PR, SP). It is a standard
QWERTY layout with one extra fixed row above it for the nine Kaingang letters that are not on QWERTY:
the nasal vowels ã ẽ ĩ ũ ỹ, the vowels á é ó, and the glottal stop written with the apostrophe ( ' ), as in pã'i.
Shift gives one capital letter, double-tap Shift locks capitals (Ã Ẽ Ĩ Ũ Ỹ Á É Ó). Long-press gives the
Portuguese accented letters, and the 😀 key opens a built-in emoji tab.

Teclado de toque para a língua kaingang: QWERTY com uma fileira fixa com as nove letras do alfabeto kaingang que
não estão no QWERTY (ã ẽ ĩ ũ ỹ á é ó e a glotal ' ). Shift = uma maiúscula; dois toques no Shift travam as
maiúsculas. A tecla 😀 abre os emojis.
