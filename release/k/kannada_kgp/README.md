Kannada KGP (Nudi) keyboard
===========================

© 2026 The Open Kannada Authors

Version 1.0

Description
-----------

Kannada on the KGP (Kannada Ganaka Parishat) phonetic layout, the standard layout of the
Government of Karnataka and of the Nudi software. People who learned to type Kannada on Nudi
can type the same keys on any computer or phone.

- A consonant key types the consonant; a vowel key after it types the vowel sign.
- `f` after a consonant joins it to the next one (ottakshara): `knfnw` types ಕನ್ನಡ.
- `ff` keeps the virama visible (ZWNJ), and `F` after ರ joins it without an arkavattu (ZWJ).
- `X` types the variant of the letter before it: ಱ, ೞ, ಽ, ೠ, ಜ಼ and the other nukta
  letters, and ೝ after ನ್.
- Digits are Kannada digits; `\` before a letter or digit types it in English.
- The phone layout keeps every key where KGP puts it, with the rarer letters on long press.

The text it types is already in the canonical form of the Open Kannada normalization profile
(https://github.com/openkannada/kannadi/blob/main/NORMALIZATION.md), and it matches
Wikimedia's jquery.ime KGP layout key for key.
