Baraha Kannada IME keyboard

Type Kannada using Latin letters. The keyboard converts what you type into Kannada script as you go, following the Baraha transliteration scheme. For example, namaskAra becomes ನಮಸ್ಕಾರ.

This project intends to extend the Baraha transliteration functionality of the Mac OS app Lipika-IME to other operating systems (e.g. Windows, Linux).

How to type

Type each Kannada word the way it sounds. The text changes into Kannada as you type: k shows ಕ್, then a turns it into ಕ, and another a makes it ಕಾ.

  • Capital letters matter. t is ತ but T is ಟ; e is ಎ but E is ಏ.
  • ಒತ್ತಕ್ಷರಗಳು (ottakSharas) form automatically. Type consonants one after another: kSh gives ಕ್ಷ, dr gives ದ್ರ್.
  • Word endings. A word ending in a consonant shows a virama (್) until you type the final vowel: raam is ರಾಮ್, raama is ರಾಮ.
  • Separating letters. Type an apostrophe between letters that would otherwise combine: k'ha gives ಕ್ಹ instead of ಖ.
