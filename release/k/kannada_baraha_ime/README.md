Baraha Kannada IME keyboard
==============

Description
-----------
Baraha Kannada IME keyboard takes Latin letters and converts them to Kannada script as you type. 

Mapping follows Baraha transliteration scheme. 

This keyboard was meant to mirror the functionality of Baraha Kannada Lipika-IME for Windows systems.
