KW SRO types Standard Roman Orthography for Plains, Woods, Swampy, and East Cree, and for Nakawē (Saulteaux). It also works for Stoney Nakoda, Algonquin, and Mohawk.

Type the vowel, then \ for ā, ] for â, [ for á, or ` for à. Some Nakawē writers use š and č: type s or c, then \.

Full instructions appear after you install it.
