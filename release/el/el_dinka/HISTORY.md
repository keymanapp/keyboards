# Dinka Change History

## 4.0 (15 NOV 2026)
* Added acute tone vowels via Shift+vowel (á, é, í, ó, ú, ɛ́, ɔ́, Ɛ́, Ɔ́)
* Added circumflex dead key (Shift+6) for breathy high tone (â, ê, î, ô, û, ɛ̂, ɔ̂, Ɛ̂, Ɔ̂)
* Added long-press popup menus for all vowel keys on touch layout
* Added custom NotoSans-Dinka font to render capital Ŋ in n-form (matching lowercase ŋ)
* Updated all font references from Arial/DejaVu/Tahoma to Noto Sans Dinka
* Added backspace handling for all new tone marks
* Updated touch layout with digraph secondary keys (th, dh, nh, ny)

## 3.0 (06 JUL 2018)
* Updated backspace logic
* Added touch device support

## 2017-08-15 2.6
* Published to github
* Added the on-screen keyboard

## 2.5 basic
* Cutdown version without the Caps Lock toggle to qwerty keyboard layout.

## 2.5 academic
* Added requirements for academic use of Dinka, i.e. add phonetic characters and diacritics used by various linguists.

## 2.5
* Bug fix

## 2.4
* Reassigned the diaeresis key

## 2.3
* Modified the logic of the 'backspace' key sequences.

## 2.2
* Streamline input of long breathy vowels; 'vvd' instead of 'vdvd', where 'v' = vowel and 'd' = diaeresis

## 2.1
* Added CAPS LOCK toggle between US QWERTY layout and Dinka layout
