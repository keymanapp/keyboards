Telugu Sanskrit Phonetic (OPTITRANS)

Description

Telugu Sanskrit Phonetic (OPTITRANS) keyboard is telugu-sanskrit input method by a modified version of OPTITRANS and Harvard-Kyoto transliteration systems.

You can use all the standard ITRANS key sequences plus key sequences such as the below.

nk->ఙ్క్, nkh->ఙ్ఖ్, ng->ఙ్గ్, ngh->ఙ్ఘ్ nch->ఞ్చ్, nCh->ఞ్ఛ్, nc->ఞ్చ్, nC->ఞ్ఛ్, nchh->ఞ్ఛ్, nj->ఞ్జ్, njh->ఞ్ఝ్, nT->ణ్ట్, nTh->ణ్ఠ్, nD->ణ్డ్, nDh->ణ్ఢ్ c->చ్, C->ఛ్, z->జ఼్, S->ష్, jn->జ్ఞ్, R->ఋ

Examples: Type saMskRta for సంస్కృత.
