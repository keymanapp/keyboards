AnnouMaké
=========

Description
-----------
Clavier pour écrire le créole guadeloupéen selon la graphie du GEREC. Disposition AZERTY où
seules deux touches changent : la touche Q donne k, la touche X donne ò ;
é, è, ç et à restent sur 2, 7, 9 et 0, et leurs capitales s'obtiennent avec le verrouillage
des majuscules.

A keyboard for Guadeloupean Creole (GEREC orthography), based on French AZERTY.
