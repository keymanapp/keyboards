Start Using Numanggang

This keyboard layout is designed for Numanggang

On a computer

Type the ; key to get the "ŋ" character. Type the ; key again to get the ";" character. Type the ; key a third time to get "ŋŋ".

Type the | key to get the "Ŋ" character. Type the | key again to get the "|" character. Type the | key a third time to get "ŊŊ".

On a phone

The phone keyboard has its own "ŋ" key, at the right end of the middle row next to L. Press Shift first to get "Ŋ".

For ";" or ":", press and hold the . key. The "|" key is on the 123 layer.

If you don't see the "ŋ" key, Keyman is still using a different keyboard. Press and hold the globe key on the Keyman keyboard, then choose Numanggang.
