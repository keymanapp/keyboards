Nepali MPP Traditional keyboard
===============================

(c) Language Technology Kendra / Madan Puraskar Pustakalaya

Description
-----------

Authentic Nepali Traditional keyboard layout conforming strictly to the official standard established by Madan Puraskar Pustakalaya (MPP) and Language Technology Kendra (LTK). 

This layout is the standardized Devanagari typewriter/traditional layout for Nepali typing, featuring direct access to standard Nepali conjunct characters (ज्ञ, द्ध, त्र, त्त, ड्ढ, द्व, ट्ट, ठ्ठ, क्ष, ङ्क, ङ्ग, द्द, ट्ठ, क्क, ह्म, द्य, ड्ड, श्र, रु) and zero-width controls.
