Nepali MPP Romanized keyboard
=============================

(c) Language Technology Kendra / Madan Puraskar Pustakalaya

Description
-----------

Nepali Romanized keyboard layout conforming strictly to the official standard established by Madan Puraskar Pustakalaya (MPP) and Language Technology Kendra (LTK). 

It allows typing Nepali in Devanagari script phonetically using a standard English (QWERTY) keyboard, including official ligatures (such as रु.), Zero-Width Non-Joiner (ZWNJ), and Zero-Width Joiner (ZWJ).
