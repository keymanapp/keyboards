Mon Hybrid keyboard
==============

Description
-----------
This Mon Hybrid keyboard is based on the classic Mon A1 layout, modified to support modern Unicode mapping. Its purpose is to make it easier for Mon people who are familiar with the traditional A1 layout to transition to Mon Unicode typing. Since it already includes muscle memory from the A1 layout, users can adapt more naturally and comfortably without having to learn an entirely new keyboard layout.
