Start Using Rohingyalish

Rohingyalish is a Latin-script way to write the Rohingya language. This keyboard provides a familiar QWERTY layout and access to characters used in Rohingyalish.

On iPhone and iPad

  • Tap a letter to type it.
  • Touch and hold supported letters to see additional characters with diacritics.
  • Tap 123 to open the numeric and punctuation layer.
  • Tap ABC to return to the alphabetic keyboard.

On a physical keyboard

Use the normal Latin keyboard layout for regular letters. Rohingyalish characters with diacritics can be entered using the keyboard's configured key sequences and modifier combinations.

Character Example sequence
á a, then '
ā a, then -
ñ, ṛ, ṭ, ḍ, ș Use the configured Right Alt combinations.

The exact character combinations depend on the keyboard rules. If a combination does not produce the expected character, check that Rohingyalish is selected as the active Keyman keyboard.

Supported characters

The keyboard includes characters such as á, ā, ḍ, ṭ, ñ, ṛ, and ș, including uppercase forms where configured.

Keyboard layout

The touch keyboard has lowercase and uppercase layers, as well as a numeric and punctuation layer. Long-press options provide access to additional diacritic characters.
