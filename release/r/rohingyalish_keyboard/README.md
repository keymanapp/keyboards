# Rohingyalish Keyboard

A Keyman keyboard for typing Rohingyalish, a Latin-script writing system used to write the Rohingya language.

## Description

This keyboard uses sequence-based key combinations to enter Rohingyalish characters with diacritics while retaining a familiar keyboard layout.

Examples include:

- `a` followed by the designated accent combination to type `á`
- `a` followed by the designated macron combination to type `ā`
- Dedicated key combinations for characters such as `ḍ`, `ṭ`, `ñ`, `ṛ`, and `ș`

Refer to the keyboard source and documentation for the complete set of mappings.

## Supported Platforms

The keyboard is configured for the following Keyman platforms:

- Windows
- macOS
- Linux
- Web
- iPhone and iPad
- Android phones and tablets

Availability and installation depend on the platform and the relevant Keyman application.
