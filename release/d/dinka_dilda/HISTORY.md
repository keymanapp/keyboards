# Dinka (DILDA) Keyboard

## Version History

### 1.0 — 16 Nov 2026

- Initial release of Dinka (DILDA) keyboard
- Based on the **Grammar of Unified Thuɔŋjäŋ** published by DILDA (Akutmɛ̈t Latueŋ Thuɔŋjäŋ), Juba, South Sudan, 2021. The unified writing system was developed through workshops organized by DILDA between 2011 and 2019, with consultation from Prof. John Myhill of the University of Haifa
- Added acute tone vowels via apostrophe dead key (`'` + vowel → á, é, í, ó, ú)
- Added circumflex tone vowels via `Shift+6` dead key (`^` + vowel → â, ê, î, ô, û)
- Diaeresis support via semicolon dead key (`;` + vowel → ä, ë, ï, ö, ü)
- Extended vowels: ɛ, ɔ with all three tone marks (ɛ́, ɛ̈, ɛ̂, ɔ́, ɔ̈, ɔ̂)
- Long-press touch popups for all vowel variants on mobile/tablet
- Digraph support: th, dh, nh, ny with long-press on touch devices
- Custom Noto Sans Dinka font with correct capital Ŋ n-form glyph
- Automatic font configuration for Keyman Developer and mobile apps
