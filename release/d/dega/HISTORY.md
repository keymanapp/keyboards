Dega Keyboard Change History
====================

4.1 (2026-11-02)
----------------
Typing
* Smart breve: type x at the end of a word and the breve goes on the last vowel (ananx → anăn, srangx → srăng, klongx → klŏng)
* Breve vowels output single precomposed characters ă ĕ ĭ ŏ ŭ (Ă Ĕ Ĭ Ŏ Ŭ) — fixes lowercase ĭ looking like a capital; matches dictionary spelling
* Removed y̆ (Y̆) — y does not take a breve in Ede
* Type English too: press the same key again to undo a conversion (s e e e → see, b o o o k → book, a d d d → add, b o x x → box)
* Word boundaries respected: x, w, z and double letters never change the previous word after a space or punctuation; xx / zz at word start stay plain
* Swapped-letter typo fixes from the Rhade dictionary (2,926 words): suiah → suaih, mnuhi → mnuih; only at word start and never when the typo is itself a Rhade or English word

Phone & tablet (touch)
* Clean Apple-style keys: no corner hints; Ede letters stay on long-press
* Phone: number row; centered home row; Apple-style bottom row 123 · 🌐 · 😀 · space · return
* Tablet: full US layout — Tab, Caps Lock, Enter, ` ~ \ | and all symbols; long-press for all Ede letters
* Emoji key 😀 with an emoji page (faces, hands with skin tones on long-press, hearts, village life: 🌾 🌳 🏠 🐘 🐔 🐟 ☕ 🍚)
* Device system font (SF Pro on Apple, Roboto on Android) for a native look and clean combining marks
* ’ on apostrophe long-press (e.g. Kơ’Ho); ` reachable on phone; ₫ and curly quotes on the number page

Desktop
* All 47 US keys verified
* AltGr (Right Alt) shortcuts: â ă ê ô ơ ư đ ƀ č ñ, breve vowels ĭ ĕ ŏ ŭ, combining ̆ ̂, and ’ ‘

Package
* Language display name: Rade → Rhade (Jarai, Koho, Bahnar, Central Mnong keep their ISO names)
* License year updated to 2021-2026
