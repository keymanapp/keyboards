Dega keyboard
==============

Description
-----------
Dega is a free keyboard designed for the indigenous languages of Vietnam's Central Highlands, including Rhade (Êđê), Jarai, Koho, Bahnar and Mnong. Created to help these communities write confidently in their own languages, Dega brings every letter of their scripts to phones, tablets and computers.

Typing is simple and intuitive. Familiar key combinations produce every special letter: double a vowel for the circumflex (â, ê, ô), add w for the horn (ơ, ư), double d for đ, and add x for the breve, even at the end of a word. Dega also corrects common typing mistakes and lets you type English with the same keyboard, without changing words you type on purpose.

For Rhade, Dega suggests words as you type from a curated dictionary of more than 3,200 words. A clean, modern layout with a number row, emoji and the device's own system font makes writing comfortable on every screen.

Dega is offered free of charge on Windows, macOS, Linux, iPhone, iPad, Android and the web, with one goal: to help preserve these languages and their writing for future generations.

**Êđê**

Dega jing sa mnơ̆ng čih hră (keyboard) arăng brei amâo mâo ênoh, mkra kơ klei blŭ djuê ana Lăn Dap Kngư, mbĭt hŏng Rhade (Êđê), Jarai, Koho, Bahnar leh anăn Mnong. Arăng mkra Dega čiăng đru phung ƀuôn sang anei dưi čih hŏng klei kjăp hlăm klei blŭ diñu pô. Dega ba grăp boh hră klei blŭ diñu kơ Fone, Ipad/Tablet leh anăn Computer.

Klei čih jing êđal blă leh anăn thâo mưng. Klei bi mguôp boh čih thâo leh mjing grăp boh hră mkăn: čih boh hră êa dua bliư̆ kơ mâo â, ê, ô; thiăm “w” kơ mâo ơ, ư; čih dua “d” kơ mâo đ; leh anăn thiăm “x” kơ mâo boh mlan “breve”, wăt ti knhal boh blŭ. Dega bi djŏ msĕ mơh klei čih soh arăng ngă nanao, leh anăn brei ih dưi čih klei Mi hŏng mnơ̆ng čih anăn, amâo bi mlih boh blŭ ih čih hŏng klei čiăng ôh.

Kơ klei Rhade, Dega mtă boh blŭ êjai ih čih, mơ̆ng sa pŏk hdruôm hră boh blŭ mâo lu hĭn kơ 3.200 boh blŭ. Sa klei dap kƀin leh anăn mrâo, mâo gah mrô, emoji leh anăn ƀoh hră pô mnơ̆ng mdê, brei klei čih ƀhbreih ti grăp boh mnơ̆ng.

Dega arăng brei amâo mâo ênoh ti Windows, macOS, Linux, iPhone, iPad, Android leh anăn web, hŏng knŏng sa klei čiăng: đru kiă kriê klei blŭ anei leh anăn klei čih diñu kơ wưng ênuk êdei.

What's new in 4.1
-----------------
* **Smart typing:** aa → â, ee → ê, oo → ô, dd → đ, ow → ơ, uw → ư, x → breve — even at the end of a word (ananx → anăn, srangx → srăng)
* **Typo fixes:** swapped letters are corrected as you type (suiah → suaih)
* **English in the same keyboard:** press the same key again to undo (seee → see, booo → boo, addd → add)
* **Clean phone & tablet layout:** Apple-style keys, number row, emoji page, system font
* **Rhade word suggestions:** 3,200+ words from a curated Ede dictionary (install the "Ede (Rhade) Dictionary Suggestions" model)
* **Desktop:** full US layout plus Right-Alt (AltGr) shortcuts for every Ede letter
