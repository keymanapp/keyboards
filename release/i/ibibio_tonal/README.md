Ibibio Tonal Keyboard
=====================

Description
-----------
A keyboard for Ibibio (ibb), a language of Akwa Ibom State, Nigeria. It types the full
Ibibio alphabet (ọ ị ʌ ñ) and all five tone marks (high, low, falling, rising, downstep)
on vowels and syllabic nasals. See the help page for typing instructions.
