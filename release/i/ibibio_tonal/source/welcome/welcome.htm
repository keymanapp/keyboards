Ñwed Ukpep: How to Type Ibibio

Usem Ibibio ke ñkpọ utañ ikọ mfo. Ibibio on your phone. This keyboard types every Ibibio letter (ọ ị ʌ ñ) and all five tones.

1. The keyboard at a glance (phone)

  • ị sits at the end of the top row, ọ ʌ at the end of the middle row, ñ next to m.
  • ˊˋ (next to the space bar) is the tone key.
  • Long-press any vowel (a e i o u ọ ị ʌ) or m n ñ to pick a toned letter in one go.
  • Comma is next to the space bar. Long-press the period for ' ? ! -
  • After numbers or symbols, the space bar takes you back to the letters.

2. Golden rule: letter first, then tone

Type the vowel (or m, n, ñ), then tap ˊˋ. Keep tapping to change the tone:

3. The five tones

ToneMarkExample

Downstepāáfēn other

Not sure of a tone? Leave it off. Untoned Ibibio is still correct Ibibio; tones make it clearer.

4. Word suggestions (predictive text)

Install the Ibibio Tonal dictionary and the keyboard suggests fully tone-marked words while you type plain letters: type abasi, get Àbàsì.

  • Android: open the dictionary file (solomonusoro.ibb.ibibio_tonal.model.kmp) and choose Keyman. Then Keyman → Settings → Ibibio → turn on Enable predictions.
  • iPhone: AirDrop or share the same file, open it in Keyman, then turn on predictions the same way.
  • Install the keyboard before the dictionary.
