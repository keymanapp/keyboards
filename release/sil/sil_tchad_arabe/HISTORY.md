Tchad Arabe Keyboard Change History
====================

3.0 (2026-08-29)
----------------
* Keep the symbols layer open until it is dismissed, instead of returning to
  the main layer after a single key
* Fix the language button on the help page rendering as an empty bar on
  Android

2.9 (2026-08-29)
----------------
* Add no-break space and narrow no-break space to the symbol layer space bar

2.6 (2026-08-29)
----------------
* Put the simpler variant first in the long-press menu on six symbol keys

2.5 (2026-08-29)
----------------
* Put hamza above alef first in the alef long-press menu

2.4 (2026-08-29)
----------------
* Swap ain and ghain, and swap jeem and khah
* Move fathatan to the symbol layer and subscript alef to the 3 key

2.3 (2026-08-28)
----------------
* Touch layout revisions from field feedback

2.2 (2026-08-23)
----------------
* Fix bottom-row key widths, which had overflowed the row budget and shrunk
  every key
* Fix the Arabic question mark key

2.1 (2026-08-20)
----------------
* Redesign the touch layout: ten columns, at most two long-press characters
  per key, and a separate symbol and number layer
* Add reh with ring, completing the consonants of the 2013 Chad National
  Alphabet decree
* Rewrite the help for both the physical and touch keyboards, in English and
  French

1.5 (2026-08-18)
----------------
* Restructure the package to match sil_tchad_qwerty conventions, with
  source/welcome/ and source/help/ folders
* Add the website help page

1.3 (2024-06-21)
----------------
* Created by SIL Tchad
