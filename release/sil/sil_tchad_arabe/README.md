Tchad Arabe Keyboard
=====================

Copyright (C) SIL Tchad

__DESCRIPTION__
This keyboard enables the typing of all the characters required by the
languages of Chad written in Arabic script, following the Chadian National
Alphabet. It provides the complete set of consonants and vowels of the 2013
decree, including the letters specific to Chad that are not part of standard
Arabic, as well as Arabic-Indic digits and the punctuation used in Chadian
publishing.

On a physical keyboard the layout follows the standard Arabic positional
layout, so typists familiar with an Arabic keyboard can use it directly. The
additional Chadian letters are reached through a dedicated key.

On phones and tablets the touch layout is laid out in ten columns, with the
less frequent letters available as long presses, and a separate layer for
digits, punctuation and symbols.
