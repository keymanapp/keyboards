Bali Simbar Keyboard Change History
===========================================

1.0 (June 1996)
------------------

* Initial release

2.0 (April 2009)
------------------

* Keyman keyboard for Windows established. It was compatible with Microsoft Office, Adobe InDesign, and CorelDRAW.

3.0 (January 2021)
------------------

* This version created to solve problems occured when using Microsoft Office 2013 and newer versions.

4.0 (July 2025)
------------------

* Bali Simbar keyboard start using UNICODE fonts. Added a touch layout for mobile phone compatibility.
