BindelWolof keyboard
====================

© 2025-2026 Serigne Mbacké Madina Gueye (Mafaatihul Bishri)

Description
-----------
BindelWolof is a keyboard for writing Wolof in Ajami (Wolofal, Arabic script),
following the Mafatihul Bishri orthography. It covers the consonants specific to
Wolof (p, c, g, ñ, ŋ and the prenasals mb, nd, nj, ng, nq), the nine vowel
qualities with their diacritics, and the characters needed to type qasidas.

Le clavier BindelWolof permet d'écrire le wolof en Ajami (wolofal) selon la
méthode Mafatihul Bishri : consonnes propres au wolof, neuf timbres vocaliques,
signes diacritiques et caractères nécessaires à la saisie des qasidas.

The package includes the SenBishri font (SIL Open Font License 1.1), an
adaptation of SenAjami4 that draws the câ' (U+0685) with the dot of the jîm.
