About Elkatib

Elkatib is an Arabic keyboard layout project developed to provide an alternative approach to typing in Arabic.

عن الكاتب

الكاتب هو مشروع لتخطيط لوحة مفاتيح عربية، يهدف إلى تقديم طريقة بديلة للكتابة باللغة العربية وتحسين تجربة المستخدم.

Getting Started

  1. Install the Elkatib keyboard.
  2. Activate it using Keyman.
  3. Switch to Elkatib when typing in Arabic.

البدء

  1. قم بتثبيت لوحة مفاتيح الكاتب.
  2. قم بتفعيلها باستخدام Keyman.
  3. اختر تخطيط الكاتب عند الكتابة باللغة العربية.
