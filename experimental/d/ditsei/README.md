Ditsei Keyboard / Teclado Ditsei
==============

© 2025 Joshua Price

Description
-----------

Ditsei keyboard / Teclado Ditsei. Forked from the
[Cabécar keyboard](https://github.com/keymanapp/keyboards/tree/master/release/c/cabecar)
by Victoria Quint, adding low tone (grave) vowel forms and rules for typing
tone, nasalization, and dieresis marks together on the same vowel regardless
of the order they're typed in.
