# Zou Script and Numerals Change History

## 1.2 (2026-11-20)

* Add vowel signs, special signs, and punctuation marks mapped to PUA range U+E04A - U+E05F.
* Update bundled TrueType font (`zou_script_and_numerals.ttf`) with new glyph entries.

## 1.1 (2026-05-26)

* Add touch layout

## 1.0 (2026-05-06)

* Initial release of the Zou Script and Numerals keyboard.
* Supports 27 Zou characters mapped to the Private Use Area (PUA) range U+E000 - U+E039.
