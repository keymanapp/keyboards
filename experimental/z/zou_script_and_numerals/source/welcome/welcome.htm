Welcome to the Zou Script Keyboard

Thank you for installing the Zou Script and Numerals keyboard. This digital tool marks a significant milestone in the preservation and promotion of the Zou community's Tibeto-Burman heritage.

Since the script is not encoded in Unicode, the codepoints in this keyboard are using Private Use Area Unicode codepoints. When, and if, the script is encoded in the Unicode, those codepoints will change.

"This Zou digital keyboard is free to use for all users to enhance learning, research and knowledge related to the Zou community." It includes the 27 Zou letters, Zou numerals, and added vowel signs, special signs, and punctuation marks mapped in the Private Use Area.

Getting Started

This keyboard is designed to integrate seamlessly with your standard hardware. It maps the 27 unique Zou alphabets, the traditional numeral system, and added vowel signs, special signs, and punctuation marks mapped in the Private Use Area to your keys.

Usage Tips

  • Zou Alphabets: Type naturally using the A-Z keys.
  • Special Characters: Don't forget the 27th letter located on the [ key, along with added vowel signs, special signs, and punctuation marks mapped in the Private Use Area.

How to Type

  • Standard Letters: Use keys A-Z for lowercase and Shift + A-Z for uppercase.
  • The 27th Letter: This character is mapped to the Left Bracket key [.
  • Numerals: Use the standard number row 0-9 to type Zou numerals.
  • Added Signs and Punctuation: Use the assigned keys/layers for added vowel signs, special signs, and punctuation marks mapped in the Private Use Area.
