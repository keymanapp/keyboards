# Version history

## 0.3.4 — 2026-10-16

* Match the requested EuroLatin-style numeric arrangement and add a currency page.
* Display grey long-press letter and symbol hints.
* Add touch sentence capitalization with manual Shift override; preserve decimal input.

## 0.3.3 — 2026-10-16

* Split numbers and symbols into two four-row pages with balanced widths.
* Keep all digits equal in width, enlarge space, and provide a dedicated symbol-page toggle.

## 0.3.2 — 2026-10-16

* Apply system sans-serif typography to suggestion text through embedded CSS.
* Widen the space key and round key corners without changing letter positions.
* Preserve platform colors and special-key icon fonts.

## 0.3.1 — 2026-10-16

* Use system sans-serif font fallbacks on phone and tablet instead of unavailable Tahoma on iOS.

## 0.3.0 — 2026-10-16

* Initial submission with desktop and phone/tablet layouts.
* Apple Russian Phonetic base with direct є/Є and additional Option/AltGr mappings.
* Language association rue, displayed as Lemko.
* Native device acceptance tests pending.
