Thank you for installing this Gĩgĩkũyũ keyboard. This keyboard is designed to help you type Gĩgĩkũyũ characters and spelling patterns conveniently.

Getting Started

Open an application where you want to type, such as Notepad or Microsoft Word, and select your Gĩgĩkũyũ keyboard through Keyman.

Special Characters

This keyboard supports Gĩgĩkũyũ characters such as ĩ, Ĩ, ũ, Ũ.

ũ/Ũ is found by clicking on the physical key "q/Q". ĩ/Ĩ is found by clicking on the physical key "x/X"

The characters "q,p,s,f,l,z,x,v" are inactive from this keyboard, with "q and x" being replaced by "ũ and ĩ" respectively. The same applies to their uppercase functions.

Special Key Sequences

Press D to type nd.
Press Alt + D to type d.
Press J to type nj.
Press Alt + J to type j, if this rule is enabled in your keyboard.
"nd and nj" are the output when d and j are clicked respectively. This is because when writing the latinized Gĩgĩkũyũ, there is no "d" without "n" and same goes for "j".

However there are ways to achieve the single "d" or "j" for use when writing names like Njoki kana Ndirangũ. This is by pressing alt + d and alt + j for single d and single j respectively.

The same applies to their uppercase functions.
