Gĩgĩkũyũ keyboard
==============

Description
-----------
Ĩno nĩ kanyakanya ya Gĩgĩkũyũ yaturirwo mwakainĩ wa 2026 AD. Ĩturĩtwo ĩteithĩrĩrie mwandĩki gũcana 
Gĩgĩkũyũ macini-inĩ. Haha ũgũkora ndemwa iria Gĩgĩkũyũ kĩhũthagĩra cia kĩ-ratini.
Kwa mũhiano, ndemwa ta q,p,s,f,l,z,x,v iria itahũthĩkaga kwandĩka Gĩgĩkũyũ itirĩ haha.
Na kũmenya maingĩ makĩria rũmĩrĩra mandĩko magũtaũra marĩa 
maratwarana na kanyakanya ĩno.
