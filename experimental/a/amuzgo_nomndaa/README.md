Ñomndaa (Amuzgo de Guerrero) keyboard
==============

Description
-----------
Teclado para escribir en la lengua ñomndaa (amuzgo de Guerrero, México) basado en la distribución Español (Latinoamérica). Incluye saltillo (ꞌ), nasal superíndice (ⁿ), vocales con macrón inferior, circunflejo y la combinación circunflejo + macrón inferior.
Conserva la base alfanúmerica intacta, por lo que permite escribir en español sin necesidad de cambiar de teclado, esto permite al usuario un aprendizje aditivo y no un metódo completamente nuevo.
Los caracteres propios del amuzgo son generados a partir del uso de una deadkey para circunflejo y también del uso de altGr para vocales con macron inferior.
