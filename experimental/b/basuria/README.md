basuria keyboard
==============

Description
-----------
Basuria keyboard for Southwestern Mandarin Xi-Nàn Koan-Hóa. The National Language Script of Basurian is a romanisation script for southwestern mandarin chinese. This keyboard applies the method of "Telex" to type Basurian letters.
